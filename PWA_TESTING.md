# PWA Features — How to Test (Vector Codes)

This site is an installable Progressive Web App powered by **next-pwa** (workbox). The service worker is generated at build time into `public/sw.js` and registers automatically in production only (disabled during `next dev`).

## 1. Install prompt (custom banner)

- The branded banner appears **after 30 seconds** on a first visit, or **~2s on the second visit** (visit count is stored in localStorage under `vc-visits`).
- Dismissal is remembered (`vc-install-dismissed`) and never shown again.
- **Chrome/Android:** the "Add to Home Screen" button triggers the native install prompt.
- **iOS Safari:** no native prompt exists; the banner shows Share &rarr; "Add to Home Screen" instructions instead.
- To reset for testing: DevTools &rarr; Application &rarr; Local Storage &rarr; delete `vc-install-dismissed` and `vc-visits`.

## 2. Offline fallback

1. Load the site normally (service worker activates after first visit + refresh).
2. DevTools &rarr; Network &rarr; **Offline** (or turn off wifi on your phone).
3. Navigate — the **/offline** page is served by the service worker: logo, "You're offline" state, Retry Connection button, WhatsApp link and a list of projects.

## 3. Cache persistence

- DevTools &rarr; Application &rarr; Cache Storage: `nextjs`, `images`, `apis` caches should be listed after visiting pages.
- Images use CacheFirst (30 days, max 64 entries); API calls NetworkFirst (5 min).

## 4. Mobile bottom navigation

- Shown below **768px** only: Home, Services, Work, Contact with gold active-state indicator.
- Desktop uses the standard top navbar (bottom nav is `md:hidden`).

## 5. Lighthouse validation

Run Lighthouse (Chrome DevTools, mobile, 4G/3G throttled):
- Target: Performance &ge;95, PWA installable, Accessibility &ge;95.
- The manifest is at `/manifest.json`; icons are SVG ("any" size) — add 192px and 512px PNGs to `public/` and update the manifest if a stricter icon audit is ever required.

## 6. Notes for future maintenance

- **SEO untouched:** `app/robots.ts` and `app/sitemap.ts` are not cached by the service worker (only same-page HTML and static assets are).
- **Push notifications (FCM):** deliberately NOT implemented yet. When ready: add firebase deps, create `public/firebase-messaging-sw.js`, and a `/notify` API route. The service worker here is auto-generated by next-pwa — extend via `runtimeCaching` or a custom `public/sw.js` only if you remove next-pwa.
- **Config:** `next.config.js` (CommonJS — required by next-pwa v5). `next.config.mjs` was removed.
